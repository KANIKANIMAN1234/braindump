## 1. 概要

| 項目 | 内容 |
|------|------|
| DBMS | PostgreSQL（Supabase マネージド） |
| テーブル数 | 業務7 + マルチテナント5（下記 §2・§6・§7） |
| 認証管理 | LINE LIFF → `members` または legacy の `line_user_id` |
| テナント分離 | `organization_id` + ロール（`lib/data-scope.js`） |
| アクセス制御 | Row Level Security（RLS）有効・Allow all ポリシー（アプリレベルでユーザー分離） |

## 3. DDL（テーブル作成 SQL）

### `tasks`

```sql
create table tasks (
  id            uuid        primary key default gen_random_uuid(),
  title         text        not null,
  due_date      date,
  priority      text        check (priority in ('高', '中', '低')) default '中',
  completed     boolean     default false,
  result        text,
  line_user_id  text,
  created_at    timestamptz default now()
);
alter table tasks enable row level security;
create policy "Allow all" on tasks for all using (true);
```

### `insights`

```sql
create table insights (
  id            uuid        primary key default gen_random_uuid(),
  content       text        not null,
  tags          text,
  exported_at   timestamptz default null,
  line_user_id  text,
  created_at    timestamptz default now()
);
alter table insights enable row level security;
create policy "Allow all" on insights for all using (true);
```

### `chat_messages`

```sql
create table chat_messages (
  id            uuid        primary key default gen_random_uuid(),
  role          text        not null check (role in ('user', 'bot')),
  content       text        not null,
  line_user_id  text,
  created_at    timestamptz default now()
);
alter table chat_messages enable row level security;
create policy "Allow all" on chat_messages for all using (true);
```

### カラム追加（既存テーブルへの適用）

```sql
-- line_user_id を全テーブルに追加
alter table tasks        add column if not exists line_user_id text;
alter table insights     add column if not exists line_user_id text;
alter table chat_messages add column if not exists line_user_id text;

-- tasks に result を追加
alter table tasks add column if not exists result text;

-- insights に exported_at を追加
alter table insights add column if not exists exported_at timestamptz default null;
```

### `prompts`（Phase 3）

```sql
-- SQL/phase3_prompts.sql を参照
create table if not exists prompts (
  id              uuid        primary key default gen_random_uuid(),
  title           text        not null,
  content         text        not null,
  tags            text,
  line_user_id    text,
  organization_id uuid        references organizations(id) on delete cascade,
  org_unit_id     uuid        references org_units(id) on delete set null,
  member_id       uuid        references members(id) on delete set null,
  created_at      timestamptz default now()
);
alter table prompts enable row level security;
create policy "Allow all" on prompts for all using (true);
```

### `daily_reflections`（Phase 5・今日の振り返り）

```sql
-- SQL/phase5_daily_reflections.sql を参照
create table if not exists daily_reflections (
  id              uuid        primary key default gen_random_uuid(),
  entry_date      date        not null default current_date,
  content         text        not null,
  line_user_id    text,
  organization_id uuid        references organizations(id) on delete cascade,
  org_unit_id     uuid        references org_units(id) on delete set null,
  member_id       uuid        references members(id) on delete set null,
  created_at      timestamptz default now()
);
alter table daily_reflections enable row level security;
create policy "Allow all" on daily_reflections for all using (true);

-- 同一ユーザー・同一日付は1件（再登録時は上書き）
create unique index if not exists daily_reflections_user_date_uniq
  on daily_reflections (line_user_id, entry_date)
  where line_user_id is not null;
```

## 4. 既存データの移行

LINE LIFF認証導入後、既存データに `line_user_id` を設定する手順。

```sql
-- YOUR_LINE_USER_ID は liff.getProfile().then(p => p.userId) で確認
update tasks             set line_user_id = 'YOUR_LINE_USER_ID' where line_user_id is null;
update insights          set line_user_id = 'YOUR_LINE_USER_ID' where line_user_id is null;
update prompts           set line_user_id = 'YOUR_LINE_USER_ID' where line_user_id is null;
update chat_messages     set line_user_id = 'YOUR_LINE_USER_ID' where line_user_id is null;
update daily_reflections set line_user_id = 'YOUR_LINE_USER_ID' where line_user_id is null;
```

## 5. 主要クエリ例

### 未完了タスク一覧（legacy・個人）

```sql
select id, title, due_date, priority
from tasks
where (completed = false or completed is null)
  and line_user_id = 'U...'
order by due_date asc nulls last, created_at asc;
```

法人メンバー向けの実際のフィルタは PostgREST 経由で `lib/data-scope.js` が適用（`org_admin` は `organization_id` のみ）。

### チャット履歴取得（直近12時間）

```sql
select id, role, content, created_at
from chat_messages
where line_user_id = 'U...'
  and created_at >= now() - interval '12 hours'
order by created_at asc;
```

### 未エクスポートの気づき取得

```sql
select id, content, tags, created_at
from insights
where line_user_id = 'U...' and exported_at is null
order by created_at asc;
```

### タグ別プロンプト一覧

```sql
select id, title, content, tags, created_at
from prompts
where line_user_id = 'U...'
order by created_at desc
limit 30;
-- タグ絞り込みはアプリ層（lib/execute-tools.js）で実施
```
