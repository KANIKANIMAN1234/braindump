## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| アプリ名 | BrainDump |
| 目的 | 日々のタスク管理・気づき記録・**プロンプト保存**を、LINE風チャットUIで自然言語により行う。**個人利用に加え、法人（テナント）単位のB2B再販**に対応 |
| フロントエンド | 静的HTML（`app/index.html` / `app/main.js` / `app/style.css`） |
| バックエンド | Vercel サーバーレス関数（`api/` ディレクトリ） |
| データベース | Supabase（PostgreSQL） |
| AI | OpenAI API（gpt-4o-mini・Function Calling） |
| 外部連携 | Dropbox API（気づきCSVエクスポート）・LINE LIFF（認証） |
| デプロイ | Vercel（GitHub 連携による自動デプロイ） |
| 対象ユーザー | 個人利用（legacy）・法人メンバー（招待登録）・運営（プラットフォームコンソール） |
| 対応端末 | スマートフォン（LINE内ブラウザ）・PC（ブラウザ） |

## 2. 機能要件

### 2.1 認証・アクセス

| # | 機能 | 説明 |
|---|------|------|
| F-01 | LINE LIFF認証 | LINEアカウントでログイン・ユーザーIDを取得 |
| F-02 | ユーザー表示 | ヘッダー右端に**法人名**・LINE表示名・プロフィール画像を表示（法人未所属は法人名なし） |
| F-03 | データ分離 | legacy は line_user_id のみ。法人メンバーはロールに応じたスコープ（代表は法人内全体） |
| F-04 | LINEリッチメニュー | LINEトーク画面からワンタップで起動 |

### 2.2 タスク管理

| # | 機能 | 説明 |
|---|------|------|
| F-05 | タスク追加 | タイトル・期限・優先度（高/中/低）を登録できる |
| F-06 | タスク一覧 | 未完了タスクを `GET /api/tasks` で取得し、優先度バッジ付き・期限昇順で一覧表示（ロールに応じたスコープ） |
| F-07 | タスク完了 | リストからタスクを選択し、完了時の結果・成果メモを記録できる |
| F-08 | タスク削除 | 不要なタスクを削除できる |
| F-09 | 優先度修正 | リストからタスクを選択し、優先度をボタン操作で変更できる |
| F-10 | 期日修正 | リストからタスクを選択し、期限日をテキスト入力で変更または削除できる |

### 2.3 気づき記録

| # | 機能 | 説明 |
|---|------|------|
| F-11 | 気づき追加 | 自由テキストで気づき・学びを記録できる |
| F-12 | タグ付け | AIが自動提案するカテゴリを複数選択できる。カスタムカテゴリの追加も可能 |
| F-13 | 気づき一覧 | 直近の気づきを一覧表示できる |
| F-14 | Dropboxエクスポート | 未エクスポートの気づきをCSV化してDropboxにアップロードできる |
| F-15 | 重複エクスポート防止 | エクスポート済みレコードには `exported_at` を付与し、次回以降は除外する |

### 2.4 チャットUI・入力

| # | 機能 | 説明 |
|---|------|------|
| F-16 | 自然言語チャット | 自由文でタスク・気づきの操作を指示できる |
| F-17 | クイックアクションボタン | 7種のボタンを常時表示（2行折り返し・中央揃え） |
| F-18 | ガイドフロー（タスク追加） | タスク名→期限→優先度を順番に誘導する |
| F-19 | ガイドフロー（タスク完了） | リストからタスク選択→完了結果を入力できる |
| F-20 | ガイドフロー（優先度修正） | リストからタスク選択→新優先度ボタン選択 |
| F-21 | ガイドフロー（期日修正） | リストからタスク選択→新期日テキスト入力 |
| F-22 | ガイドフロー（気づき追加） | 気づき入力→AIカテゴリ選択まで誘導する |
| F-23 | タイピングインジケーター | AI応答待ち中に「…」アニメーションを表示する |
| F-24 | チャット履歴の永続化 | 直近12時間のやり取りをDBに保存し、再アクセス時に復元する |
| F-25 | 音声入力 | マイクボタンで音声を認識しテキスト入力できる（連続録音モード） |

### 2.5 B2B・マルチテナント（Phase 1 / 2）

| # | 機能 | 説明 |
|---|------|------|
| F-26 | 法人登録（運営） | 運営コンソールで法人を登録し、代表管理者へ招待 URL を発行する |
| F-27 | 代表の初回登録 | 招待 URL から LINE ログインし `line_user_id` を紐づける（手入力禁止） |
| F-28 | 組織階層の初回設定 | 代表が 0〜3 段から選択し組織ツリーを確定する（**事後変更なし**） |
| F-29 | 0段法人 | 代表のみ。メンバー招待・設定後の ⚙️ 非表示 |
| F-30 | 連鎖招待 | org_admin / unit_admin / dept_admin がロールに応じてメンバーを招待 |
| F-31 | 法人名表示 | ヘッダーに `organizations.name` を表示する |

## 4. 非機能要件

| 項目 | 内容 |
|------|------|
| 認証 | LINE LIFF認証（アクセストークン方式・自動更新） |
| セキュリティ | APIキーはVercel環境変数で管理。全APIでLINEトークン検証を実施 |
| データ分離 | legacy: line_user_id。法人: organization_id + ロールベーススコープ |
| 可用性 | Vercel・Supabaseのマネージドインフラに依存 |
| パフォーマンス | 1回のチャットAPIレスポンスは5秒以内を目標 |
| スケーラビリティ | Supabase無料プランで動作すること |

## 8. 制約・前提条件

- LINEアカウントが必須（LIFF認証）
- Supabase 無料プランで動作すること
- Dropbox リフレッシュトークンは長期有効だが、アプリの権限変更時は再取得が必要
- チャット履歴は12時間以内のもののみ復元する
- 音声入力はブラウザのマイク許可が必要（iOS LINE内ブラウザでは制限あり）
- 組織階層の**事後変更**は実装しない（初回設定のみ）
- 代表管理者の `line_user_id` は**招待 URL 経由のみ**（DB 手入力は運用禁止）
- 運営向けプラットフォームコンソールは `/app/platform-console.html`（一般ユーザーの管理画面ではない）
