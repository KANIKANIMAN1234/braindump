## 2. 機能詳細

### FN-01 タスク追加

| 項目 | 内容 |
|------|------|
| トリガー | [＋ タスク追加]ボタン、または「タスクを追加」等の自然言語入力 |
| フロー | ガイドフロー（タスク名 → 期日 → 優先度）または自然言語で一括解析 |
| 入力項目 | タイトル（必須）・期日（省略可）・優先度（高/中/低、省略時は「中」） |
| DB操作 | `tasks` に INSERT（`POST /api/tasks` で直接追加も可） |
| バリデーション | `priority` は '高'/'中'/'低' のいずれか。無効値は '中' に補正 |

### FN-02 タスク一覧

| 項目 | 内容 |
|------|------|
| トリガー | [📋 タスク一覧]ボタン（**API 直取得**）、または自然言語（AI 経由） |
| API | `GET /api/tasks` → `{ tasks: [...] }` |
| スコープ | `lib/data-scope.js`（legacy: line_user_id、org_admin: organization_id 等） |
| 表示 | `addTaskListMessage()` でテーブル形式。0件はメッセージのみ |

### FN-03 タスク完了

| 項目 | 内容 |
|------|------|
| トリガー | [✅ タスク完了]ボタン |
| フロー | タスクボタン選択 → 完了結果入力（任意） → 完了 |
| DB操作 | `tasks` を `completed=true, result=?` で UPDATE（`PATCH /api/tasks` で直接更新） |

### FN-05 優先度修正

| 項目 | 内容 |
|------|------|
| トリガー | [🔄 優先度修正]ボタン |
| フロー | タスクボタン選択 → 優先度ボタン（高/中/低）選択 → 更新 |
| DB操作 | `tasks` を `priority=?` で UPDATE（line_user_idでフィルタ） |
| バリデーション | 選択ボタン自体が '高'/'中'/'低' のみのため不正値は入らない |

### FN-06 期日修正

| 項目 | 内容 |
|------|------|
| トリガー | [📅 期日修正]ボタン |
| フロー | タスクボタン選択 → 日付テキスト入力 → 更新 |
| 入力形式 | `YYYY-MM-DD` 形式、または「なし」でNULL（期日削除） |
| DB操作 | `tasks` を `due_date=?` で UPDATE（line_user_idでフィルタ） |

### FN-07 気づき追加

| 項目 | 内容 |
|------|------|
| トリガー | [💡 気づき追加]ボタン、または自然言語 |
| フロー | 本文入力 → AIカテゴリ提案 → 複数タグ選択 → 登録 |
| DB操作 | `insights` に INSERT（`add_insight` ツール） |
| 登録後表示 | `addInsightListMessage()` でタグ別一覧を標準表示（FN-33） |

### FN-34 プロンプト追加

| 項目 | 内容 |
|------|------|
| トリガー | [✨ プロンプト追加]ボタン、または自然言語 |
| フロー | タイトル入力 → 本文入力 → AIカテゴリ提案 → 複数タグ選択 → 登録 |
| DB操作 | `prompts` に INSERT（`add_prompt` ツールまたは `POST /api/prompts`） |
| 登録後表示 | `addPromptListMessage()` でタグ別一覧を標準表示（FN-36） |
| デフォルトタグ | カテゴリ未選択時の一覧絞り込みは「文章作成」 |

### FN-09 気づきエクスポート

| 項目 | 内容 |
|------|------|
| トリガー | [📤 気づきエクスポート]ボタン、または自然言語 |
| DB操作（読込） | `insights` から `exported_at IS NULL AND line_user_id=?` を SELECT |
| 変換 | CSV形式（ヘッダー: id, content, tags, created_at） |
| アップロード | Dropbox `/braindump/insights/insights_YYYYMMDD.csv` にアップロード |
| DB操作（更新） | アップロード成功後に `exported_at=now()` で UPDATE |
| 認証方式 | Dropbox リフレッシュトークン（DROPBOX_APP_KEY + DROPBOX_APP_SECRET + DROPBOX_REFRESH_TOKEN） |

### FN-18 LINE LIFF認証

| 項目 | 内容 |
|------|------|
| SDK | LINE LIFF SDK v2（CDN `https://static.line-scdn.net/liff/edge/2/sdk.js`） |
| LIFF ID | `2010175951-S9r18QtA` |
| 初期化 | ページ読み込み時に `liff.init({ liffId })` を実行 |
| 未ログイン | `liff.isLoggedIn() === false` の場合は `liff.login()` で認証ページへ |
| トークン | `liff.getAccessToken()` で取得（有効期限12時間・自動更新） |
| API認証 | 全APIリクエストに `Authorization: Bearer <accessToken>` を付与 |
| サーバー検証 | `GET https://api.line.me/v2/profile` にトークンを送りレスポンスから `userId` を取得 |

### FN-19 ユーザーデータ分離

| 項目 | 内容 |
|------|------|
| 対象テーブル | `tasks` / `insights` / `prompts` / `chat_messages` |
| 分離キー | `line_user_id` カラム（LINE userId = `U` + 32文字） |
| 実装 | 全Supabaseクエリに `.eq("line_user_id", lineUserId)` を付与。INSERTにも `line_user_id` を含める |

### FN-21 音声入力

| 項目 | 内容 |
|------|------|
| 録音 | `navigator.mediaDevices.getUserMedia` + `MediaRecorder` |
| 送信 | 録音停止後 Blob を Base64 化して `POST /api/transcribe` |
| モデル | `gpt-4o-mini-transcribe`（サーバー側） |
| 起動 | [🎤]ボタンをタップで録音開始、再タップで停止→文字起こし |
| フォールバック | `MediaRecorder` 非対応時は🎤ボタンを無効化しテキスト入力を案内 |

### FN-22 Dropboxリフレッシュトークン認証

| 項目 | 内容 |
|------|------|
| 方式 | OAuth 2.0 リフレッシュトークン（offline アクセス） |
| 必要な環境変数 | `DROPBOX_APP_KEY` / `DROPBOX_APP_SECRET` / `DROPBOX_REFRESH_TOKEN` |
| ライブラリ | `dropbox` npm パッケージ（`Dropbox` クラス） |
| 動作 | Dropbox SDK が内部でリフレッシュトークンを使い短期アクセストークンを自動取得 |
| 有効期限 | リフレッシュトークン自体はアプリの権限変更がない限り無期限 |

## 3. OpenAI ツール定義（Function Calling）

`api/chat.js` が OpenAI に渡すツール定義の概要。

| ツール名 | 用途 |
|---------|------|
| `add_task` | タスク登録（title・due_date・priority） |
| `list_tasks` | 未完了タスク一覧取得 |
| `complete_task` | タスク完了（task_id・result） |
| `delete_task` | タスク削除（task_id） |
| `update_task` | タスク更新（task_id・priority? / due_date?） |
| `add_insight` | 気づき登録（content・tags） |
| `list_insights` | 気づき一覧取得（limit・tag/tags で絞り込み可） |
| `export_insights_to_dropbox` | 気づきCSVエクスポート |
| `add_prompt` | プロンプト登録（title・content・tags） |
| `list_prompts` | プロンプト一覧取得（limit・tag/tags で絞り込み可） |

### システムプロンプト（抜粋）

```
あなたはタスク管理・日々の気づき記録・プロンプト保存をサポートするアシスタントです。
気づきを記録するときは add_insight を呼び出し、タグを tags 引数に渡すこと。
プロンプトを記録するときは add_prompt を呼び出し、タイトル・本文・タグを渡すこと。
ツールを呼ばずに「追加しました」などと返答してはいけない。
```
