## 3. コンポーネント詳細

### 3.1 フロントエンド（`app/`）

| ファイル | 役割 |
|---------|------|
| `app/index.html` | チャット画面HTML（LIFF SDK・ローディングオーバーレイ・8ボタン） |
| `app/style.css` | LINE風UI（タスク・気づき・プロンプトリスト・タグバッジ） |
| `app/main.js` | LIFF初期化・ステートマシン・構造化リスト表示・履歴 |
| `app/org-admin.js` | 組織ウィザード（0〜3段）・メンバー招待 |
| `app/platform-console.*` | 運営コンソール（法人登録・招待 URL コピー） |
| `app/favicon.png` | BrainDumpロゴ（ブラウザタブ・ホーム追加アイコン） |

### 3.1b 共有ライブラリ（`lib/`）

| ファイル | 役割 |
|---------|------|
| `lib/data-scope.js` | tasks / insights / prompts / messages の PostgREST スコープ |
| `lib/require-member.js` | LINE 検証 + members 解決 |
| `lib/handlers/*.js` | auth / org / platform 各ハンドラ |

### 3.2 サーバーレス関数（`api/`）

| ファイル | エンドポイント | 役割 |
|---------|--------------|------|
| `api/chat.js` | `POST /api/chat` | OpenAI Function Calling + Supabase CRUD + 履歴保存 |
| `api/config.js` | `GET /api/config` | Supabase接続設定の返却 |
| `api/messages.js` | `GET /api/messages` | 直近12時間のチャット履歴取得 |
| `api/tasks.js` | `GET/POST/PATCH /api/tasks` | タスク一覧・直接追加・完了 |
| `api/prompts.js` | `GET/POST /api/prompts` | プロンプト一覧・直接追加 |
| `api/transcribe.js` | `POST /api/transcribe` | 音声文字起こし |
| `api/suggest-categories.js` | `POST /api/suggest-categories` | AIカテゴリ提案（気づき/プロンプト） |
| `api/auth/[action].js` | `/api/auth/me` 等 | メンバー・activate |
| `api/org/[action].js` | `/api/org/*` | 組織 setup / tree / invite |
| `api/platform/[action].js` | `/api/platform/*` | 運営（Platform Secret） |

### 3.3 認証フロー

| ステップ | 処理 |
|---------|------|
| 1 | LIFF SDK初期化（`liff.init()`） |
| 2 | 未ログインなら `liff.login()` でLINE認証画面へ |
| 3 | ログイン後、`liff.getAccessToken()` でトークン取得 |
| 4 | 全APIリクエストに `Authorization: Bearer <token>` を付与 |
| 5 | サーバー側で `GET https://api.line.me/v2/profile` を呼び出し `userId` を取得 |
| 6 | 法人メンバーは `members` + `data-scope`、未登録は legacy で `line_user_id` のみ |

### 3.4 データベース（Supabase）

| テーブル | 用途 |
|---------|------|
| `tasks` / `insights` / `prompts` / `chat_messages` | 業務データ + tenant 列 |
| `organizations` / `org_units` / `members` | マルチテナント・組織 |
| `member_invites` / `platform_audit_logs` | 招待・監査 |

## 4. データフロー

### 4.1 通常チャット

```
[ユーザー] テキスト or 音声入力 → 送信
    ↓
[main.js] liff.getAccessToken() → POST /api/chat { message }
    ↓
[api/chat.js]
  → LINE /v2/profile でtoken検証 → lineUserId取得
  → OpenAI (gpt-4o-mini + tools)
  → ツール実行（applyTasksScope / scopedRowData で絞込・INSERT）
  → chat_messages にINSERT
  → { reply, tasks?: [...], insights?: [...], insightTag?, prompts?: [...], promptTag? }
    ↓
[main.js] addMessage() / addTaskListMessage() / addInsightListMessage() / addPromptListMessage()
```

### 4.2 ガイドフロー（タスク完了・優先度/期日修正）

```
[ボタン押下] → GET /api/tasks（未完了タスク取得）
    ↓
[main.js] タスクをボタン一覧として表示
    ↓
[ユーザー] タスクをボタンで選択
    ↓
追加入力（結果 or 新優先度 or 新期日）
    ↓
POST /api/chat → 更新実行
```

### 4.3 ページ読み込み時（LIFF認証 + 履歴復元）

```
liff.init() → liff.isLoggedIn() 確認
  ├─ 未ログイン → liff.login()（LINEログイン画面へ）
  └─ ログイン済 → getAccessToken() + getProfile()
       ↓
  ヘッダーにアイコン・名前表示
       ↓
  GET /api/messages → 履歴表示 or 初回挨拶
```

## 7. 制約事項

| 項目 | 内容 |
|------|------|
| 認証必須 | LINEアカウントなしではアクセス不可 |
| チャット履歴 | 12時間以内のみ復元。それ以前のデータはDBに残るが画面には表示されない |
| 音声入力 | iOS LINE内ブラウザでは動作しない場合あり（SafariまたはChromeで開く） |
| Dropboxトークン | リフレッシュトークン方式のため基本的に期限なし。アプリ権限変更時は再取得が必要 |
| Supabase RLS | `Allow all` ポリシー。アプリレベルで line_user_id によるデータ分離を実施 |
